## 🚀  ## Documentación del Proceso

### ¿Cuál fue el prompt exacto que mejores resultados te dio?

"Crea el CSS base para una Landing Page de e-commerce moderna llamada TechStore. Utiliza un diseño minimalista inspirado en Samsung y Apple. Usa CSS Grid para organizar un catálogo de 8 productos de forma responsiva (4 columnas en escritorio, 2 en tablet y 1 en móvil). Diseña botones atractivos con un color de acento fuerte y efectos hover suaves. Emplea una paleta de colores minimalista con mucho espacio en blanco, tipografía moderna y alto contraste para los precios. Las tarjetas de producto deben tener bordes redondeados, sombras sutiles y una ligera animación al pasar el cursor para transmitir confianza y profesionalismo."

### 🚀 ¿Qué principio de usabilidad (UX) consideraste para diseñar los botones de "Añadir al carrito"?

Se aplicó el principio de **jerarquía visual y retroalimentación inmediata (feedback)**. Los botones "Añadir al carrito" fueron diseñados con un color contrastante, tamaño adecuado y una ubicación consistente dentro de cada tarjeta para que el usuario identifique rápidamente la acción principal. Además, se añadieron efectos hover que proporcionan una respuesta visual inmediata al interactuar, mejorando la percepción de control y facilitando el proceso de compra.
