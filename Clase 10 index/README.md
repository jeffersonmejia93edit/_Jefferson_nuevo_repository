## 🚀Documentación en README.md: Escribe un breve párrafo (3-4 líneas)
respondiendo a esta pregunta técnica: ¿Por qué utilizamos Grid para
separar el panel lateral del contenido principal, en lugar de intentar
hacerlo todo únicamente con Flexbox?
------------------------------------------------------
Utilizamos CSS Grid para dividir el panel lateral y el contenido principal porque este diseño requiere una estructura bidimensional clara, con áreas definidas para cada sección. Grid permite establecer columnas de tamaño fijo y flexible de forma sencilla, manteniendo una separación consistente entre ambas partes de la interfaz. Aunque Flexbox también podría lograrlo, está pensado principalmente para distribuciones unidimensionales.
