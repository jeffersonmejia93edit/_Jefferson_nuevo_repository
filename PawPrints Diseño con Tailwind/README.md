## 🚀 # PawPrints - Landing Page con Tailwind CSS

## Descripción

Este proyecto consiste en el desarrollo de una **Landing Page** para el refugio de animales **PawPrints**, utilizando **HTML5** y **Tailwind CSS** mediante CDN. El objetivo es crear una interfaz moderna, responsiva y con una estructura semántica adecuada, aplicando utilidades de Tailwind para el diseño y la distribución de los elementos.

## Tecnologías utilizadas

* HTML5
* Tailwind CSS (CDN)
* CSS

## Estructura del proyecto


PawPrints/
│── index.html
│── style.css
└── README.md

## Características implementadas

* Estructura semántica con `header`, `main`, `section`, `article` y `footer`.
* Diseño responsivo utilizando las utilidades de Tailwind CSS.
* Header con navegación.
* Sección Hero con llamado a la acción.
* Galería de mascotas con tarjetas.
* Footer con información de contacto y redes sociales.
* Uso de Grid y Flexbox para la distribución de los elementos.

## Respuesta a la pregunta técnica

Usar prefijos como `md:` o `lg:` directamente en el HTML con Tailwind permite aplicar estilos responsivos de forma rápida y organizada sin escribir Media Queries en un archivo CSS separado. Esto reduce la cantidad de código, mejora la legibilidad y facilita el mantenimiento del proyecto, ya que todos los estilos del componente se encuentran en un solo lugar. Además, acelera el desarrollo y evita cambiar constantemente entre el HTML y el CSS.
