## 🚀 Landing Page de Cafetería - Café El Buen Grano
Este proyecto utiliza CSS Grid para organizar la estructura principal de la página (encabezado, contenido y pie de página) y Flexbox para distribuir y alinear los elementos internos. Flexbox es ideal para cambiar fácilmente la dirección de los elementos entre columna y fila mediante `flex-direction`, lo que simplifica la adaptación responsive. Aunque Grid también podría hacerlo, Flexbox resulta más sencillo y eficiente para controlar la disposición de componentes en una sola dimensión, como la imagen y el texto del producto.
